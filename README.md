# Marks Percentage Calculator

I made a **Marks Percentage Calculator** using **HTML, CSS and JavaScript**. It's fast. Gives accurate results.

This tool helps students quickly calculate their exam percentage by entering their marks. It's simple. Works well on phones.

## Features

* You get your percentage away

* The results are accurate

* It looks clean. Works well on any device

* You can use it on a computer, tablet or phone

* I built it using HTML, CSS and JavaScript

* It's free and easy to use

## How It Works

To use it enter:

* Your obtained marks

* The total marks

The calculator shows you:

* Your percentage

This makes it great, for checking exam results, assignments and grades.
